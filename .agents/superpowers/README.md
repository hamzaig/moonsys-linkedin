# Project-local Superpowers

Official Superpowers 7.0.2 skills are installed as individual folders under `.agents/skills/`, alongside UI/UX Pro Max.

Source: https://github.com/obra/superpowers/tree/22f0b463e7a5e579904dd6211a520321035526f7

Start with `../skills/using-superpowers/SKILL.md`. Existing user instructions take precedence. This installation does not change global Codex settings or install hooks. Skill files are available for manual use in this session; automatic discovery must be checked in a fresh Codex session.

The upstream MIT license is retained in `LICENSE`, and `INSTALLATION.json` records provenance and SHA-256 hashes.
